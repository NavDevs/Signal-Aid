02. METHOD

INTELLIGENT EMERGENCY RESPONSE

Signal Aid is an emergency response system built with Flutter that empowers ambulance and fire truck drivers to navigate urban traffic with unprecedented speed. Using machine learning, the app preempts traffic signals along emergency routes in real time.

From the moment a dispatch is accepted, Signal Aid calculates the optimal route, clears intersections ahead, and provides live tracking — reducing response times when every second matters.

03. CAPABILITIES

THE SYSTEM

01 🔒

Driver Authentication

Secure login with Driver ID and Vehicle Number. Role-based access ensures only authorized personnel operate the system.

02 🗺

Dispatch Planning

Real-time route planning with ETA calculation. Accept emergency dispatches and receive optimized navigation instantly.

03 ⚡

Criticality Levels

Choose between Normal, High, and Critical emergency levels. The system adapts route priority and signal preemption urgency accordingly.

04 🚦

Signal Preemption

ML-powered traffic signal clearing for emergency vehicles. Intersections are preempted in real time to create a clear corridor.

05 ⏱

Live Tracking

Real-time countdown timer with intersection status updates. Monitor every signal change as you approach.

06 📡

Live Dispatch

Socket.IO pushes new emergency requests the instant a citizen reports them. No polling, no delays — instant notification.

07 📊

Trip History

Complete log of all emergency responses with statistics. Review past trips, response times, and route efficiency.

08 🌙

Dark Theme

Eye-friendly dark UI optimized for emergency vehicle cockpits. Reduced glare during night operations.

04. PROCESS

HOW IT WORKS

01

Authenticate

Driver logs in with secure credentials — Driver ID and assigned Vehicle Number. The system validates identity and connects to dispatch.

02

Dispatch

Accept incoming emergency requests in real time. The system calculates the optimal route, sets criticality level, and prepares signal preemption.

03

Navigate

ML clears traffic signals ahead of your route. Real-time tracking guides you through every intersection with live countdown and status updates.
